## V10Plugins

> 为智简魔方业务系统打造的免费开源插件索引仓库

---

### 项目简介

智简魔方官方应用商店中的插件大多需要付费购买。对于刚接触这个系统、或者想先体验再决定的用户来说，付费门槛显得有些高。这个项目的想法很简单：为大家提供一套**免费、开源、可以自由使用**的插件集合。

V10Plugins 由 RuiNexus 发起和维护，主要收集、整理并持续开发适用于智简魔方业务系统 V10 的各种插件。不论你是刚准备搭建业务系统的新手，还是已经在深度使用、希望扩展更多功能的老用户，这里都希望能帮你省下一些时间和费用。

> 智简魔方业务系统（ZJMF-CBAP v10）是一款基于 PHP + MySQL 的开源业务管理核心，扩展性不错，安装也很快（官方说 5 分钟内可以完成）。系统自带应用商店，开发者可以免费提交应用并获得收益。由于智简魔方在行业内已经有比较多的用户基础，它的应用生态也慢慢丰富起来了。

---

### 项目目标

- **降低使用门槛**：提供免费插件，让更多人可以低成本体验和扩展系统功能。
- **丰富应用生态**：作为官方商店的补充，覆盖更多小众或实用的业务场景。
- **社区共建共享**：鼓励开发者一起参与，让开源插件的质量和种类越来越好。

### 如何贡献

我们很欢迎大家一起参与 V10Plugins 的建设。

由于这个仓库只是一个**插件索引**，不直接存放插件的源代码，所以贡献方式是这样的：

1. 你自己开发一个符合智简魔方 V10 规范的插件，并把代码托管在公开的代码仓库（GitHub、GitLab、Gitee 等都可以）。
2. 确保你的仓库里包含：
   - 完整的插件源码
   - 清晰的 README.md（说明功能、安装方法、配置方式等）
   - 一份开源许可证（推荐 MIT）
3. 通过以下任一方式提交你的插件信息：
   - 在本仓库的 [Issues](https://github.com/RuiNexus/V10Plugins/issues) 中新建一个主题，标题格式为 `[插件投稿] 插件名称`，内容包含：插件仓库地址、插件类别、功能简介、作者信息
   - 或者发送邮件到 `ruinexus@163.com`
4. 项目维护者会进行审核，主要看：
   - 代码是否遵循智简魔方开发规范
   - 插件是否安全、可用
   - 开源协议是否合规
5. 审核通过后，我们会把你的插件信息添加到上面的 **插件列表** 中，并附上你的仓库链接。

**审核的一些小要求**  
- 插件必须完全免费且开源。  
- 不能包含恶意代码、后门、广告或侵犯他人权益的内容。  
- 最好能在智简魔方 V10 上实际测试过。  

**如果你有需要的插件功能**  
欢迎在 Issues 里提出，也许会有其他开发者感兴趣并动手实现。

### 开源协议
RuiNexus 开发的插件默认采用 MIT 许可证。你可以自由使用、修改和分发代码，但请保留原始版权声明。  
（贡献者自己开发的插件可以根据个人意愿选择协议，但必须是一个开源协议。）
